<br>

yanawa is an experimental strongly typed application language designed to make common software explicit without making it ceremonial.

It aims for strong guarantees without repeating what the compiler already knows, keeps ordinary programming familiar where familiar models already work, and treats typed application boundaries and compiler-aware tooling as the places worth experimenting. Derived information may stay implicit. Meaningful behavior should stay visible.

<br>

yanawa is under active design. There is no stable language, released compiler, runtime, or package ecosystem yet.
